1. 프로젝트 주제

매일의 건강 수치를 한 줄로 기록하면, 서버가 BMI·혈압·혈당을 자동 분류하고 경고를 띄우며, 쌓인 검진 시계열로 "다음에 위험군이 될 사람"을 학습된 모델이 미리 찾아 알려주는 API.

개인은 /ui에서 자신의 검진 추이와 AI 소견을 보고, 관리자는 /dashboard에서 전체 회원의 위험군을 한눈에 관리한다. 단순 CRUD를 넘어, 실제 인구통계 기준으로 생성한 5,000명·9만 건의 검진 데이터 위에서 머신러닝 위험 예측 + 통계 검정 + LLM 소견을 결합했다.

2. 핵심 기능

구분기능
기록 관리 (필수)건강 수치 CRUD · 날짜 검색 · 통계 · BMI 자동계산 · 혈압/혈당 분류 · 경고 생성
인증·권한회원가입/로그인(JWT) · user / admin / superadmin 3단 권한 · 계정 상태(활성/휴면/탈퇴)
관리자 대시보드위험군 카드 · 회원/관리자/활동로그/통계 탭 · 회원 상세 · 위험군 드릴다운
AI 위험 예측학습된 로지스틱 모델이 "다음 분기 위험 전환 확률" 예측 (PR-AUC 0.535, 무작위의 5.5배)
행동 인사이트생활습관 메모–지표 효과를 Welch t-검정 + 다중비교 보정으로 유의한 것만 판정
AI 소견위 숫자를 GPT가 문장으로 서술 (판단 안 함, 유의 효과만 언급)

4. 화면 캡쳐 — 관리자 대시보드

▲ 회원 관리 — 상단 위험군 카드(비만·고혈압·당뇨·경고) + 회원 목록(이름·인적정보·건강상태·검진수). 위험 회원은 좌측 빨강 스트라이프.
▲ 관리자 탭 — 권한 지정/변경 (superadmin 전용)
▲ 활동 로그 — 로그인·기록생성·실패 이력 (기간·동작 필터)
▲ 통계 탭 — 분기별 위험 판정 비율 추이 + BMI·혈압·혈당 분포 (클릭 시 해당 회원 목록)

5. 화면 캡쳐 — 사용자 화면 & AI

▲ 개인 화면 — 종합판정 KPI(위험) · AI 건강 소견(GPT) · 오늘 기록 입력폼(범위 가드) · 내 일일 기록(BMI 자동계산·분류)
▲ 검진 추이 — 혈압·혈당·BMI 시계열 (임계선 밴드)
▲ 병원 검진 이력 — 분기별 지표 + 생활습관 메모

6. AI 파이프라인 — "판단하는 AI"

단순 규칙이 아니라, 세 단계가 각자 역할을 나눠 판단한다.

단계담당하는 일검증
위험 확률ML (로지스틱)다음 분기 위험 전환 예측PR-AUC 0.535 (무작위의 5.5배)
행동 효과통계 (Welch t)메모–지표 인과의 유의성95% 신뢰구간 + 다중비교 보정
소견 서술LLM (GPT)숫자를 문장으로유의 효과만 언급, 없는 값 생성 금지

예: "권다은 환자는 70세 여성으로 현재 위험군… 위험 등급 2, 기초 위험도 9.78%" (실제 GPT 출력, 위 화면 캡쳐).
